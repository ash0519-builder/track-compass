# 트랙 나침반 · HSU 진로로드맵 e-Advisor

한성대학교 학생의 관심 분야, 희망 직무, 강점을 바탕으로 **두 전공트랙 조합을 추천**하고, 1학년 1학기부터 4학년 2학기까지 **교과·비교과 이수 로드맵**을 만들어 관리하는 웹앱입니다.

2026 HSU 진로로드맵 e-Advisor 웹앱 개발 공모전 출품용 프로토타입입니다.

**배포 주소:** https://ash0519-builder.github.io/track-compass/

## 주요 기능

| 단계 | 기능 |
| --- | --- |
| 1. 진로 진단 | 입학 모집단위, 학년·학기, 관심 분야(최대 4), 희망 직무(최대 3), 강점(최대 3) 입력 |
| 2. 트랙 추천 | 입학 유형에 맞는 선택 범위 안에서 1·2트랙 조합 Top 3와 추천 이유, 트랙별 적합도 상위 8개 |
| 3. 학기별 로드맵 | 8개 학기 교과·비교과 계획 자동 생성, 체크하면 트랙별 이수 과목·비교과포인트 진행률 갱신 |
| 4. AI 상담 | 추천 이유, 이번 학기 할 일, 비교과 포인트, 트랙 변경 시뮬레이션, 졸업요건 질문에 답변 |

입력과 체크 상태는 브라우저(localStorage)에만 저장됩니다. 서버로 전송되는 개인정보는 없습니다.

## 추천 로직

트랙 적합도 S(t)는 학생의 선택과 트랙 태그가 겹치는 비율(0~1)을 가중합합니다.

```
S(t) = 0.5 × 관심 분야 일치 + 0.3 × 희망 직무 일치 + 0.2 × 강점 일치
```

두 트랙 조합 점수 C(a, b)는 평균 적합도에, 서로 다른 단과대학 조합일 때 융합 가산점을 더합니다(최대 110점).

```
C(a, b) = (S(a) + S(b)) / 2 + 0.1 × [단과대학(a) ≠ 단과대학(b)]
```

- 상상력인재학부(유형 1): 1·2트랙 모두 전체 트랙에서 선택, 적합도가 높은 쪽을 1트랙으로 둡니다.
- 그 외 모집단위(유형 2): 1트랙은 입학한 단과대학 안에서, 2트랙은 전체에서 선택합니다.

구현: [`src/lib/scoring.ts`](src/lib/scoring.ts)

## 프로젝트 구조

```
src/
  data/tracks.ts      트랙 목록(42개), 태그, 예시 교과목, 비교과 설정
  lib/scoring.ts      적합도·조합 점수·추천 이유
  lib/roadmap.ts      학기별 로드맵 생성, 진행률 계산
  lib/advisor.ts      상담 응답 (규칙 기반, LLM 연동 지점)
  lib/storage.ts      브라우저 저장
  components/         진단, 추천, 로드맵, 상담, 요약 화면
```

## 실행 방법

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173/track-compass/)
npm test         # 추천·로드맵·상담 로직 테스트
npm run build    # 타입 검사 후 dist/ 생성
```

`main` 브랜치에 푸시하면 GitHub Actions가 테스트·빌드 후 GitHub Pages에 자동 배포합니다(`.github/workflows/deploy.yml`).

## 데이터 안내

- 트랙 목록은 [한성대 학부(과)·트랙 안내](https://www.hansung.ac.kr/hansung/6208/subview.do)의 2026학년도 기준입니다. 실기 기반 예술학부 전공은 제외했습니다.
- 디지털콘텐츠·가상현실트랙은 2027학년도 11월 트랙 선택부터 지능형실감미디어공학트랙으로 이름이 바뀝니다([학사조직 개편 안내](https://www.hansung.ac.kr/hansung/7573/subview.do)).
- **교과목과 비교과 포인트는 예시 데이터입니다.** 개발 기간에 각 트랙 홈페이지의 교과목 로드맵·트랙 졸업요건으로 교체할 예정입니다.
- HSP 100pt는 공모전 공지 기준이며, 비교과포인트 800pt 졸업요건은 2016학년도 이후 입학자 안내 기준으로 현재 기준 확인이 필요합니다.
- 추천은 참고용이며, 최종 트랙 선택은 지도교수 상담 후 결정해야 합니다.
