# 트랙 나침반 · HSU 진로로드맵 e-Advisor

한성대학교 학생의 입학 모집단위, 관심 분야, 희망 직무, 강점을 바탕으로 **제1·제2트랙 조합을 추천**하고, 1학년 1학기부터 4학년 2학기까지 **교과·비교과 이수 로드맵**을 만들어 관리하는 웹앱입니다.

2026 HSU 진로로드맵 e-Advisor 웹앱 개발 공모전 출품작입니다.

- **웹사이트:** https://ash0519-builder.github.io/track-compass/
- **아이디어 기획서:** [docs/기획서.md](docs/기획서.md)

## 주요 기능

| 탭 | 기능 |
| --- | --- |
| 1. 진로 진단 | 입학 모집단위(13개), 주·야, 학년·학기, 관심 분야·희망 직무·강점, 비교과로 키우고 싶은 분야 입력 |
| 2. 트랙 추천 | 학사 규칙을 지킨 제1·제2트랙 조합 Top 3, 추천 이유, 선택 조건(트랙기초 성적, 선발, 주야 교차 등) |
| 3. 학기별 로드맵 | 두 트랙의 공식 교육과정으로 8개 학기 계획 생성, 교양·비교과 포함, 체크하면 졸업요건 진행률 갱신 |
| 4. 비교과 추천 | 스마트자기관리시스템의 실제 비교과 432개를 진로 진단·선택 트랙으로 추천, 영어·외국어/AI·SW·데이터/진로·취업 등 10개 카테고리, 로드맵에 담기 |
| 5. 상담 | 추천 이유, 이번 학기 할 일, 트랙 변경 시뮬레이션, 비교과포인트, 졸업요건, 제1트랙 선택 범위 |
| 6. 졸업요건·제도 | 졸업요건, 비교과포인트, 트랙 선택·변경 규칙, 2027학년도 개편 명칭 (공식 출처 링크) |

입력과 체크 상태는 브라우저(localStorage)에만 저장되고 서버로 전송되지 않습니다.

유의사항

- 예술학부(실기 전공)와 글로벌인재대학(외국인 유학생 대상)은 트랙 선택 방식이 달라 제외했습니다.
- 부동산트랙(2023 로드맵)과 인테리어디자인트랙(2025 로드맵)은 이수구분 대신 기초·핵심·심화·활용 분류만 공개되어 있습니다.
- 인테리어디자인트랙은 공개된 로드맵 과목이 33학점이라 트랙 졸업학점(39학점)에 못 미칩니다. 트랙에 확인이 필요합니다.
- 교양 과목의 학기 배치와 전공선택 과목 선택은 예시입니다.
- 관심·직무·강점 태그는 추천 계산을 위해 각 트랙 교육과정을 보고 붙인 값이며 학교 공식 분류가 아닙니다.

## 추천 로직

트랙 적합도 S(t)는 학생의 선택과 트랙 태그가 겹치는 비율(0~1)을 가중합합니다.

```
S(t) = 0.5 × 관심 분야 일치 + 0.3 × 희망 직무 일치 + 0.2 × 강점 일치
C(a, b) = (S(a) + S(b)) / 2 + 0.1 × [단과대학(a) ≠ 단과대학(b)]
```

후보는 한성대 전공트랙제도 규칙으로 거릅니다.

- 제1트랙은 소속 모집단위(학부) 안에서만 고릅니다. 상상력인재학부는 거의 모든 트랙에서 고를 수 있습니다.
- 학과 입학생(뷰티디자인매니지먼트학과, 창의융합대학 학과)은 제1전공이 본인 학과입니다.
- 주간은 주간 트랙, 야간은 야간 트랙만 제1트랙이 될 수 있고, 주·야 교차는 제2트랙에서만 허용합니다.
- 창업트랙은 제2트랙으로만, 창의융합대학 학과를 제2트랙으로 고르면 선발(주야별 30% 이내) 안내를 붙입니다.
- 컴퓨터공학부 트랙은 트랙기초 과목 성취 기준을 안내합니다.

로드맵은 트랙마다 전공기초·전공필수를 모두 넣고 전공선택으로 39학점을 채웁니다. 두 트랙에 같은 과목이 있으면 학점은 한 번만 셉니다.

비교과 추천 점수 (`src/lib/programs.ts`)

- 비교과로 키우고 싶은 분야(카테고리) 일치 +12, 관심 분야·희망 직무 일치 각 +3(최대 2개), 강점 일치 +1
- 내 트랙 이름이 들어간 프로그램 +6, 내 트랙 학부·학과가 운영 +3, 다른 학부 전용 전공 프로그램 -4
- 지금 신청 가능 +1.5, 여러 학기 운영 +0.5, 인재인증 +0.5, 포인트가 높을수록 최대 +2
- 담은 프로그램이 없는 학기는 추천 상위 프로그램으로 로드맵을 채움

## 프로젝트 구조

```
src/
  data/curricula.ts   트랙·학과별 공식 교육과정 (학년-학기·이수구분·과목명)
  data/tracks.ts      트랙·모집단위 정보, 주야 개설, 선택 조건, 출처 URL
  data/rules.ts       졸업요건, 교양필수, 공통 비교과 일정, 트랙 제도, 2027 개편
  data/programs.ts    스마트자기관리시스템 비교과 프로그램 432개
  lib/programs.ts     비교과 카테고리 분류와 추천 점수
  lib/scoring.ts      적합도, 제1·제2트랙 후보 규칙, 조합 점수, 선택 조건
  lib/roadmap.ts      학기별 로드맵 생성, 진행률 계산
  lib/advisor.ts      상담 응답
  components/         화면 (진단, 추천, 로드맵, 상담, 졸업요건·제도)
docs/기획서.md         아이디어 기획서
```

## 실행 방법

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173/track-compass/)
npm test         # 추천 규칙·로드맵·상담 테스트
npm run build    # 타입 검사 후 dist/ 생성
npm run build:file   # dist/를 HTML 파일 하나로 합침 → release/트랙나침반_eAdvisor.html
```

`release/트랙나침반_eAdvisor.html`은 서버 없이 더블클릭만으로 실행되는 제출용 파일입니다.

`main` 브랜치에 푸시하면 GitHub Actions가 테스트·빌드 후 GitHub Pages에 자동 배포합니다.
