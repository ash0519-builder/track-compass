## 1. 프로젝트 개요

**트랙 나침반**은 학생의 입학 모집단위, 관심 분야, 희망 직무, 강점을 분석해 한성대 학사 규칙에 맞는 제1·제2트랙 조합을 추천하고, 두 트랙의 공식 교육과정으로 졸업까지의 학기별 교과·비교과 로드맵을 만들어 관리하는 웹앱입니다.

## 2. 문제 정의

한성대 학생은 2학년 진학 시 제1트랙과 제2트랙을 직접 골라 자신의 전공을 설계합니다. 선택지가 많고 규칙이 복잡하지만, 판단에 필요한 정보는 여러 페이지에 흩어져 있습니다.

**제도 현황** (한성대 공식 안내 기준)

- 제1트랙은 소속 모집단위 안에서 반드시 골라야 하고, 제2트랙은 다른 단과대학에서도 자유롭게 고릅니다. 상상력인재학부는 거의 모든 트랙에서 고를 수 있습니다. ([전공트랙제도](https://www.hansung.ac.kr/hansung/6213/subview.do))
- 주·야 개설, 컴퓨터공학부 트랙기초 성취 기준, 창의융합대학 학과의 제2트랙 선발(주야별 30% 이내) 같은 조건이 트랙마다 다릅니다.
- 졸업에는 교과 130학점(전공 78 = 트랙당 39, 교양 31, 자유선택 21)과 비교과포인트 800pt가 필요합니다. ([이수체계](https://www.hansung.ac.kr/hansung/6217/subview.do))
- 2027학년도에는 디자인대학→AI디자인대학, 창의융합대학→AI융합대학 등 학사조직 명칭이 바뀝니다. ([대학전체](https://www.hansung.ac.kr/hansung/6081/subview.do))

**학생이 겪는 어려움**

1. **정보가 흩어져 있다.** 교과목은 44개 트랙·학과 홈페이지에, 졸업요건과 트랙 규칙은 학사 안내에, 비교과는 학생성공센터에 따로 있습니다.
2. **나에게 맞는 조합을 알기 어렵다.** 관심사와 진로를 트랙으로 연결해 주는 도구가 없습니다.
3. **트랙을 바꾸면 학점이 꼬인다.** 변경 시 이미 취득한 트랙 전공학점은 일반선택으로 바뀌고, 학교는 트랙 간 상호 전공과목 변경신청 제도를 따로 운영합니다.
4. **비교과를 계획적으로 챙기기 어렵다.** 학기당 200pt 상한이 있어 몰아서 채울 수 없고, 한 학기에만 수백 개가 열리는 프로그램 가운데 내 진로에 맞는 것을 찾기 어렵습니다.

## 4. 서비스 흐름

진로 진단 → 트랙 조합 추천 → 학기별 로드맵 → 학기마다 이수 체크·진행률 확인 → (진로가 바뀌면) 다시 진단. 상담은 추천 결과와 로드맵을 근거로 답합니다.

## 5. 추천 로직

점수는 설명 가능한 규칙으로 계산하고, 후보는 학사 규칙으로 먼저 거릅니다.

```
S(t)   = 0.5 × 관심 분야 일치 + 0.3 × 희망 직무 일치 + 0.2 × 강점 일치
C(a,b) = (S(a) + S(b)) / 2 + 0.1 × [단과대학(a) ≠ 단과대학(b)]
```

- 제1트랙 후보: 소속 모집단위의 트랙(상상력인재학부는 전체), 본인 주·야 개설 트랙, 제2트랙 전용 제외
- 제2트랙 후보: 제1트랙을 뺀 전체 (주·야 교차 허용)
- 제2트랙 없이: 트랙제 입학생은 2학년 진학 시 제2트랙이 필수라 '미정'으로만 둘 수 있고, 학과 소속은 심화전공(학과 78학점) 또는 융합전공Ⅱ(학과 57 + 부전공 21학점)로 계획
- 로드맵: 두 트랙에 같은 과목이 있으면 학점을 한 번만 세고 전공선택을 더 배치
- 학기 분산: 한 학기가 18학점을 넘으면 선택 교양 → 전공선택 → 전공필수 순서로 같은 학기(1·2학기)에 열리는 가벼운 학기로 옮김 (전공기초·교양필수는 고정)
- 다시 들을 과목: 지난 학기에 체크하지 않은 전공기초·전공필수·교양필수를 같은 학기에 열리는 남은 학기 중 학점 여유가 있는 가장 이른 학기에 배치

운영 원칙: 추천은 참고용이며 최종 선택은 학생과 지도교수가 합니다. 개인정보는 서버로 보내지 않고 브라우저에만 저장합니다.

## 8. 팀 가이드라인 반영 (설계 결정)

| 논의 항목 | 결정 | 이유 |
| --- | --- | --- |
| 학습데이터: 무엇을, 어떻게 모으나 | 들은 과목과 성적. 종합정보시스템 성적 조회 표를 복사해 붙여넣거나(정규식으로 과목명·성적·학점만 읽음) 과목을 직접 추가 | 학교 시스템과 연동할 수 없어 학생이 직접 넣는 방식이 가장 확실. 입력은 기기에만 저장 |
| 학습데이터 분석 기준 (유사도) | 들은 과목이 그 트랙 교육과정 과목이면 1.0(전공기초 1.2, 전공필수 1.1), 같은 학부 다른 트랙 0.5, 같은 단과대학 0.25, 과목명 키워드가 트랙 관심 분야와 같으면 0.3. 여기에 성적 비율(A+ 1.0 ~ D0 0.5, F는 감점)과 학점을 곱해 더하고 15학점을 만점으로 | '같은 전공 > 같은 학부 > 같은 단과대' 순서로 가까움을 정하면 학생에게 설명하기 쉽고, 성적이 좋은 분야에 점수가 더 가게 됨 |
| 전공 추천 기준 | 학사 규칙으로 후보를 거른 뒤 흥미(관심 50%·직무 30%·강점 20%) 65% + 학습 35%. 학습 데이터가 없으면 흥미 100%. 모듈형 시범 10개 트랙은 희망 직무로 진로 경로(모듈 조합)까지 추천 | 1학년은 성적이 없어 흥미 중심, 학년이 오를수록 실제 이수 이력이 반영됨 |
| 교과 로드맵 방식 | 학기별 보드(표). 에타 시간표처럼 고치기: 과목 ⋯ 메뉴로 학기 옮기기·다른 전공선택으로 바꾸기·교양 실제 과목명 적기, 끌어서 옮기기, '+ 과목 추가', 되돌리기 | 졸업요건(학점) 확인에는 표가 가장 정확하고, 수정은 학생에게 익숙한 시간표 방식이 쉬움 |
| 비교과 로드맵 방식 | 게임 패스처럼: 목표(얻고 싶은 것)를 고르면 입문 → 성장 → 도전 3단계 길을 만들고, 포인트 패스(200·400·600·800pt)가 졸업요건까지 채워짐. 예) 영어: English Corner → Open Activity·Conversation Partner → 영어권 어학연수·스피치 대회 | 로드맵 = 목표·단계·마일스톤·일정. '포인트만 채우기'보다 목표가 있는 길이 한성인재인증·포트폴리오에도 남음 |
| 비교과 추천 기준 | 목표 카테고리 일치(+12) 최우선, 관심·직무 키워드, 내 트랙·학부 연계, 대상(다른 학부 전용은 맞춤 추천에서 제외), 학년 적합(신입생·진로탐색 1~2학년, 취업·현장실습 3~4학년), 지금 신청 가능, 포인트 | 대상·시기가 맞지 않는 프로그램을 추천하면 신청할 수 없거나 효과가 적음 |
| 로드맵 관리 (일정) | 캘린더처럼: 담은·추천 프로그램의 신청 마감·운영 시작을 날짜순으로 보여 주고, .ics 파일로 휴대폰·구글 캘린더에 넣기 | 비교과는 신청 마감을 놓치는 경우가 가장 많음 |
| 교양필수·선택필수교양 포함 | 포함. 교양필수 13학점은 과목명으로, 선택필수교양 15학점은 5개 배분이수 영역(인문학적·사회과학적·과학기술·예술과 스포츠·융합적 상상력) 자리로 넣고 실제 과목명을 적을 수 있음 | 교양 31학점이 졸업요건이라 빠지면 학기별 학점 계획이 틀어짐 |
| 'AI 분석'을 쓸지, 정규식으로 할지 | 분석·추천·상담은 정규식·규칙으로 하고, 더 자유로운 질문은 'AI 챗봇용 요약'을 복사해 원하는 AI에 붙여넣도록 연결 | 같은 입력에 늘 같은 결과(설명 가능), HTML 파일 하나로 오프라인 동작, 성적이 밖으로 나가지 않음, API 키·비용 없음. 앱 안에 AI를 직접 붙이려면 개인정보 동의와 서버가 필요해 고도화 과제로 둠 |
| 안내 캐릭터 | 화면마다 'TIP' 도움말 자리를 둠 | 학교 마스코트 이미지는 사용 승인을 받은 뒤 TIP 자리에 넣을 수 있음 |
